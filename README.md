# USD/MXN Macro & News Monitor (IN2TECHMX)

Plataforma de fácil visualización y toma de decisiones para el tipo de cambio USD/MXN.
Desarrollada bajo el esquema de gobernanza y arquitectura Swarm IN2TECHMX (ADR-006).

## Características Principales
1. **Cono Probabilístico Interactivo a 30 Días:** Simulación vectorial Monte Carlo con difusión y saltos de Merton (Merton Jump-Diffusion, 1976) sobre 5,000 trayectorias empíricas.
2. **Control Deslizante Día a Día:** Inspección detallada día por día de soportes (P10), mediana (P50), resistencias (P90) y catalizadores del mercado.
3. **Asistente Táctico de Decisión y Cobertura:** Estrategias y calculadora interactiva para perfiles de Importador (comprador de USD) y Exportador (vendedor de USD).
4. **Feed de Noticias Reales:** Corpus de 2,407 artículos de 249 medios independientes clasificados por arquetipos macroeconómicos y dirección del choque.
5. **Estudio de Eventos MacKinlay (1997):** Ranking dual de los mayores choques históricos con Retorno Anómalo Acumulado (CAR) y p-values calculados.
